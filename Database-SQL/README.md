# 📚 Library Database System

A simple Java console-based application that manages library books using PostgreSQL and JDBC.

## 🚀 Project Overview

This project demonstrates how Java applications interact with a relational database using JDBC. Users can perform CRUD operations (Create, Read, Update, Delete) on book records stored in a PostgreSQL database.

## 📚 Features

* Add New Books
* View All Books
* Update Book Details
* Delete Books
* Store Data in PostgreSQL Database
* JDBC Database Connectivity
* Menu-Driven Console Application

## 🛠 Technologies Used

* Java
* JDBC
* PostgreSQL
* pgAdmin
* VS Code
