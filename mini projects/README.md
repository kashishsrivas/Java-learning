# Java Mini Projects 🚀

This folder contains beginner-to-intermediate Java mini projects created while learning Java and backend development concepts.

## Projects Included

### 1. Console Calculator

A simple calculator using:

- Methods

- Conditions

- User Input

### 2. Number Analyzer

Features:

- Even/Odd Check

- Prime Number Check

- Factorial

### 3. Student Marks System

Features:

- Store Marks

- Calculate Average

- Find Highest Marks

- Grade System

### 4. String Utility App

Features:

- Reverse String

- Palindrome Check

- Count Vowels

- Character Frequency

### 5. ATM Machine

Features:

- Deposit Money

- Withdraw Money

- Check Balance

## Concepts Used

- Loops

- Arrays

- Strings

- Methods

- Conditions

- Scanner Class
