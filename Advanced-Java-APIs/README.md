* Functional Programming Basics
* Lambda Syntax

3. Stream API

* Filtering Data
* Mapping Data
* Sorting Collections
* Aggregation Operations

4. Functional Interfaces

* Single Abstract Method (SAM)
* Custom Functional Interfaces
* Lambda Integration

5. Date & Time API

* LocalDate
* LocalTime
* LocalDateTime
* Formatting Dates
